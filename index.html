Diagramador ER

O Diagramador ER é uma ferramenta desenvolvida para facilitar a criação visual de diagramas de banco de dados.
Com ele, você pode organizar tabelas, definir colunas e estabelecer relacionamentos de forma simples e intuitiva,
além de gerar automaticamente o código SQL correspondente ao seu projeto.
